# AnimePortable

A lightweight, keyboard-first Windows anime player inspired by OneAnime: find an anime, pick an episode, watch it in the built-in player, resume later. Go, FLTK and in-process libmpv; unzip and run, no installer. Linux and macOS are planned after Windows is complete.

Current status: [docs/STATUS.md](docs/STATUS.md). Engineering docs start at [docs/README.md](docs/README.md); contributors and AI agents start at [AGENTS.md](AGENTS.md).
