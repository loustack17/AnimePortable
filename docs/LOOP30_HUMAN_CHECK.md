## 驗收項目

| 項目 | 操作與預期結果 |
| --- | --- |
| 作品詳情 | 從 Search 以 Enter 或滑鼠開啟作品。顯示標題、原文標題、簡介；有中繼資料時顯示封面、季別／年份、製作公司與集數。缺資料或封面失敗有清楚提示，不停在載入中，也不自動播放。 |
| 選集與鍵盤 | 方向鍵選擇集數，Enter 選取、Space 播放目前聚焦的那一集。Tab 換到另一集後，方向鍵與 Space 以該集為起點；焦點清楚可見，播放集數正確，集數順序不任意重排。 |
| 繼續觀看與進度 | 播放一集並前進一段時間，返回詳情再按繼續觀看。恢復對應作品／集數與保存位置；已完成或沒有可用紀錄時不假裝可續播，集數列顯示觀看進度或完成狀態。 |
| 返回與失敗復原 | 開啟作品後立即返回、切換另一作品或關閉；較晚的資料不能覆蓋目前作品。若來源暫時無法播放，返回詳情後仍能重試或選其他集，不出現無作用的按鈕。 |
| 視窗與滑鼠 | 縮小到允許的最小尺寸，再放大。按鈕、集數與分頁不超出右側或底部；以方向鍵移到清單末端時焦點仍看得到。滑鼠點選、捲動、分頁與返回均可使用。 |

詳細範圍與驗證狀態見 [LOOP30_DETAIL.md](LOOP30_DETAIL.md)。上述結果尚未由使用者執行，不能標為 PASS。
