AnimePortable 第一個預覽版（alpha）。核心功能可以使用，但功能尚未齊全，也可能有已知或未知的問題。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看。
- 用星號追蹤作品；「追蹤」頁顯示最新集數、看到第幾集與「有新集數」。
- 首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。

## 使用方式

1. 下載 `AnimePortable-v0.1.0-alpha.1-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料（觀看進度、追蹤）存在同一個資料夾的 `data/` 內，不會上傳。要搬移或刪除，直接處理整個資料夾即可。

## 已知限制

- 這是預覽版，尚未完成安全與資源的完整檢查。
- 「時間表」、「歷史紀錄」、「設定」頁尚未建立。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。

## 第三方元件

ZIP 內含固定雜湊的 `libmpv-2.dll`，來源與授權說明見 `licenses/libmpv.txt`；其他第三方授權見 `THIRD_PARTY_NOTICES.md`。

問題回報請到 GitHub Issues。
