AnimePortable 第二個預覽版（alpha）。新增「歷史紀錄」頁，並簡化「追蹤」頁。功能仍未齊全，也可能有已知或未知的問題。

## 這一版的變更

- 新增「歷史紀錄」頁：每部看過的作品一列，顯示最近看的集數、進度（例如 7:52 / 24:00 或「已看完」）與上次觀看的日子。
- 在「歷史紀錄」按作品，從上次的位置繼續播放；已看完的集數從頭播放。
- 按列右側的 ✕ 移除該作品的觀看紀錄，連同儲存的播放位置一起刪除；之後再播放會從頭開始。
- 「追蹤」頁只顯示看到第幾集與播放位置，不再顯示「有新集數」，作品依名稱排列。
- 觀看紀錄只存在這台電腦，不會上傳。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看（首頁「繼續觀看」或「歷史紀錄」）。
- 用星號追蹤作品；首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。

## 使用方式

1. 下載 `AnimePortable-v0.1.0-alpha.2-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料（觀看進度、追蹤）存在同一個資料夾的 `data/` 內，不會上傳。從 v0.1.0-alpha.1 升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄。

## 已知限制

- 這是預覽版，尚未完成安全與資源的完整檢查。
- 「時間表」、「設定」頁尚未建立。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。

## 第三方元件

ZIP 內含固定雜湊的 `libmpv-2.dll`，來源與授權說明見 `licenses/libmpv.txt`；其他第三方授權見 `THIRD_PARTY_NOTICES.md`。
