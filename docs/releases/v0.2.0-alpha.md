AnimePortable v0.2.0-alpha（預覽版）。新增「時間表」頁，並讓整個程式可以只用鍵盤操作。功能仍未齊全，也可能有已知或未知的問題。

從這一版起，版本號改為：新增功能升第二位（例如 0.2.0 → 0.3.0），只修問題升第三位（例如 0.2.0 → 0.2.1），後面的 alpha（早期預覽）或 beta（功能接近完成）表示階段，完整版為 1.0.0。上一版是 v0.1.0-alpha.2。

## 這一版的變更

- 新增「時間表」頁：從今天起一週七欄，每部新番一張卡片，標題為繁體中文。資料來自 Bangumi 的每週放送表，先顯示上次存下的內容，再在背景更新。
- 在時間表按作品：程式已有片源的作品直接開啟詳情；其他作品會切到「搜尋」並以作品名稱搜尋片源。
- 鍵盤操作：每個畫面都有明顯的焦點框線，方向鍵移動，Enter 或空白鍵開啟或播放。
- 按 `/` 或 Ctrl+K 在任何畫面開啟「搜尋」，並選取搜尋框的文字，可直接輸入新的作品名稱。
- 按 Esc 返回上一頁；在首頁按 Esc 不會關閉程式。
- 播放中按 Esc 停止播放並回到首頁（進度會記住）；按 `/` 或 Ctrl+K 停止播放並開啟搜尋。
- 「追蹤」、「歷史紀錄」清單用上下鍵移動時會自動捲動，讓焦點那列保持可見；重新載入或看完影片回來後，焦點不會消失。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看（首頁「繼續觀看」或「歷史紀錄」）。
- 用星號追蹤作品；首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。
- 查看接下來 7 天的新番時間表。
- 不用滑鼠完成：開啟程式、搜尋、開啟作品、選集數、播放。

## 使用方式

1. 下載 `AnimePortable-v0.2.0-alpha-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料（觀看進度、追蹤、時間表）存在同一個資料夾的 `data/` 內，不會上傳。從舊版升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄。

## 已知限制

- 這是預覽版，尚未完成安全與資源的完整檢查。
- 「設定」頁尚未建立。
- 時間表只有星期，沒有播出時間與集數；只有名稱與季別完全相同的作品會直接開啟，其他作品改用搜尋。
- 部分鍵盤配置需要按 Shift 才能打出 `/`，這時請改用 Ctrl+K 開啟搜尋。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。
