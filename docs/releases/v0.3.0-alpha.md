AnimePortable v0.3.0-alpha（預覽版）。新增「設定」頁、播完自動播下一集、播放速度，首頁開啟更快且離線時也能看到上次的資料。功能仍未齊全，也可能有已知或未知的問題。上一版是 v0.2.0-alpha。

## 這一版的變更

### 設定
- 新增「設定」頁，分為 外觀、播放、網路、資料、關於。每項設定立即儲存，重新開啟程式後保留。
- 主題：「跟隨系統 | 暗色 | 明亮」三選一，跟隨系統時依 Windows 的淺色/深色。首頁右上角的主題按鈕移除。
- 播放：自動下一集、自動播放（自動下一集載入的那一集要直接播放還是停在暫停）、從上次位置繼續播放（預設開啟）、硬體解碼（畫面黑屏或閃退時可關閉）。
- 網路：代理伺服器「不使用 | 系統 | 手動」，手動可填 `主機:連接埠`（例如 127.0.0.1:7890），並可「測試連線」，成功綠字、失敗紅字。只支援 HTTP 代理，不支援帳號密碼、PAC 與 SOCKS。
- 資料：可把資料（觀看進度、追蹤、設定）搬到其他資料夾。程式會複製資料、確認無誤後自動重新開啟；原資料夾的資料不會被刪除。「恢復預設位置」可搬回程式旁的 `data`。
- 關於：目前版本、「檢查更新」（只在按下時連線到 GitHub）、GitHub 專案頁。
- 所有提示視窗改為與程式一致的樣式，按 Esc 等於取消。

### 播放
- 一集正常播完後，在同一個播放視窗自動播放下一集；最後一集播完會停止。
- 播放器下方新增速度按鈕（0.75×–2×），選過的速度會記住。
- 播放器的選集清單會直接捲到目前這集，集數多時有捲軸。
- 可在播放器和「歷史紀錄」直接追蹤作品。

### 首頁與資料
- 開啟程式時先顯示上次存下的資料，不必等網路；連不上時首頁顯示一行說明，而不是錯誤。
- 首頁「繼續觀看」會顯示最近看完的一集為「已看完」。
- 視窗縮放後版面與點擊都正常。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看，播完自動下一集。
- 追蹤作品；首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。
- 查看接下來 7 天的新番時間表。
- 全程可只用鍵盤操作。

## 使用方式

1. 下載 `AnimePortable-v0.3.0-alpha-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料存在同一個資料夾的 `data/` 內（或你在「設定 → 資料」選的資料夾），不會上傳。從舊版升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄；第一次開啟會自動更新資料格式，之後請不要再用舊版開啟這份資料。

## 已知限制

- 這是預覽版，尚未完成安全與資源的完整檢查。
- 介面只有繁體中文；英文與日文介面在下一階段。
- 尚無「跳過片頭」；之後會改用社群標註的片頭時間，只在片頭期間顯示按鈕。
- 代理只支援 HTTP；Windows 系統代理若是 SOCKS 或自動設定指令碼（PAC），程式會直接連線，「測試連線」會說明。
- 資料位置只能選本機磁碟，不能選網路磁碟。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。
