AnimePortable v0.4.0-beta（預覽版，beta）。新增英文與日文介面、只在片頭期間出現的「跳過片頭」，開啟程式時也不再多出一個黑色主控台視窗。主要功能已經齊全，但尚未完成正式版前的安全與資源檢查。上一版是 v0.3.0-alpha。

## 這一版的變更

### 不再出現黑色視窗
- 之前的版本開啟程式時，旁邊會多一個黑色的主控台視窗。這一版起只會出現程式本身的視窗。

### 跳過片頭
- 播到片頭時，畫面右下角出現「跳過片頭」按鈕；片頭以外的時間不會出現。
- 按下按鈕或按 S 鍵，直接跳到片頭曲結束的地方，按鈕隨即消失；往回拖進片頭，按鈕會再出現。
- 片頭時間來自社群標註的 AniSkip。只有在播放某一集時才查詢，送出的只有 MyAnimeList 編號、集數與這集的長度。沒有標註資料的集數不會出現按鈕，播放不受影響。

### 語言
- 設定 → 外觀 → 語言：「繁體中文 | English | 日本語」，切換後所有畫面立即改變，不必重新開啟程式，並會記住。
- 作品名稱、簡介等來自網站的內容不翻譯。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看，播完自動下一集，片頭可一鍵跳過。
- 追蹤作品；首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。
- 查看接下來 7 天的新番時間表與觀看紀錄。
- 「設定」頁可調整主題、語言、播放、代理伺服器與資料位置。
- 全程可只用鍵盤操作。

## 使用方式

1. 下載 `AnimePortable-v0.4.0-beta-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料存在同一個資料夾的 `data/` 內（或你在「設定 → 資料」選的資料夾），不會上傳。從舊版升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄；第一次開啟會自動更新資料格式，之後請不要再用舊版開啟這份資料。

## 已知限制

- 這是預覽版，尚未完成正式版前的安全與資源完整檢查。
- 「跳過片頭」只在 AniSkip 有標註、且找得到對應作品時出現。有些作品在 Anime1 上第二季的集數接續第一季編號（13、14…），這些集數不會出現按鈕。
- 代理只支援 HTTP；Windows 系統代理若是 SOCKS 或自動設定指令碼（PAC），程式會直接連線，「測試連線」會說明。
- 資料位置只能選本機磁碟，不能選網路磁碟。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。

## 第三方元件

ZIP 內含固定雜湊的 `libmpv-2.dll`，來源與授權說明見 `licenses/libmpv.txt`；其他第三方授權見 `THIRD_PARTY_NOTICES.md`。
