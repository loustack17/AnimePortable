AnimePortable v1.0.0，第一個正式版。這一版完成了正式版前的安全與資源檢查，並修正了檢查中發現的問題；除了「硬體解碼」切換後的提示，功能與 v0.4.1-beta 相同。上一版是 v0.4.1-beta。

## 可以做什麼

- 搜尋 Anime1 上的作品，查看封面、簡介、季別與集數。
- 在程式內直接播放，可從上次位置繼續觀看，播完自動下一集，片頭可一鍵跳過。
- 追蹤作品；首頁「近期更新」列出追蹤作品最近 7 天出現的新集數。
- 查看接下來 7 天的新番時間表與觀看紀錄。
- 「設定」頁可調整主題、語言（繁體中文、English、日本語）、播放、代理伺服器與資料位置。
- 全程可只用鍵盤操作。

## 這一版的變更

### 安全
- 播放器只接受 MP4 影片。之前若影片來源被人動過手腳、送來偽裝成影片的播放清單，播放器可能會自行連到清單上的其他位址；現在這種內容會直接無法播放。
- 程式只從自己的資料夾與 Windows 系統資料夾載入元件，不會載入放在其他位置、名稱相同的檔案。
- 加強對 Anime1 回應內容的檢查，異常的回應不會讓程式卡住或佔用大量記憶體。

### 設定
- 切換「硬體解碼」後會跳出提示：下次開啟播放器時生效，不需要重新開啟程式。

### 檢查結果
- 反覆開關播放器、切換集數、自動下一集、取消搜尋數百到數千次，記憶體與背景工作都不會持續增加。
- 縮到最小化放置 15 分鐘後，工作管理員顯示程式約使用 10 MB 記憶體。

## 使用方式

1. 下載 `AnimePortable-v1.0.0-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料存在同一個資料夾的 `data/` 內（或你在「設定 → 資料」選的資料夾），不會上傳。從舊版升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄。v0.4.1-beta 的資料可直接沿用，不需要更新資料格式。

## 已知限制

- 少數作品仍找不到簡介，例如 Anime1 把多個部分合成一條的「Dr.STONE 新石紀 SCIENCE FUTURE」。
- 「跳過片頭」只在 AniSkip 有標註、且找得到對應作品時出現。
- 代理只支援 HTTP；Windows 系統代理若是 SOCKS 或自動設定指令碼（PAC），程式會直接連線，「測試連線」會說明。
- 資料位置只能選本機磁碟，不能選網路磁碟。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。

## 第三方元件

ZIP 內含固定雜湊的 `libmpv-2.dll`，來源與授權說明見 `licenses/libmpv.txt`；其他第三方授權見 `THIRD_PARTY_NOTICES.md`。
