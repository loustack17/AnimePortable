AnimePortable v1.0.1，修正與內部整理版。使用上的功能與 v1.0.0 相同。上一版是 v1.0.0。

## 這一版的變更

### 修正
- 作品詳情頁的「繼續」按鈕改用和首頁「繼續觀看」相同的判斷。觀看紀錄如果已經播到影片長度的最後，詳情頁不會再提供「繼續」。
- 播放失敗紀錄 `playback-failures.log` 會寫明失敗是不是出在代理伺服器（`proxy` 表示連不上代理，`proxy_refused` 表示代理拒絕連線），不再一律寫成 `unknown`。

### 內部整理
- 整理程式碼，移除重複與不再使用的部分，為下一個大版本做準備。畫面、文字和操作方式都沒有改變。

## 使用方式

1. 下載 `AnimePortable-v1.0.1-windows-amd64.zip`。
2. 解壓到一個可寫入的資料夾（例如桌面上的新資料夾）。
3. 執行 `animeportable.exe`。不需要安裝。

資料存在同一個資料夾的 `data/` 內（或你在「設定 → 資料」選的資料夾），不會上傳。從舊版升級時，先關閉舊版，再把舊資料夾的 `data/` 整個複製到新資料夾，即可保留紀錄。v1.0.0 的資料可直接沿用，不需要更新資料格式。

## 已知限制

與 v1.0.0 相同：

- 少數作品仍找不到簡介，例如 Anime1 把多個部分合成一條的「Dr.STONE 新石紀 SCIENCE FUTURE」。
- 「跳過片頭」只在 AniSkip 有標註、且找得到對應作品時出現。
- 代理只支援 HTTP；Windows 系統代理若是 SOCKS 或自動設定指令碼（PAC），程式會直接連線，「測試連線」會說明。
- 資料位置只能選本機磁碟，不能選網路磁碟。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能顯示 SmartScreen 警告。
- 只支援 Windows 64 位元。
- 影片來源是 Anime1 網頁，對方改版時可能暫時無法使用。

## 第三方元件

ZIP 內含固定雜湊的 `libmpv-2.dll`，來源與授權說明見 `licenses/libmpv.txt`；其他第三方授權見 `THIRD_PARTY_NOTICES.md`。
